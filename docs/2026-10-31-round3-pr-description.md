# جولة 3 موحّدة — تقوية عدم الاتصال وإكمال ADR-0010 (يعتمد التحقق الكامل على الشواهد أدناه)

**الهدف:** `integration/kayyal-unified` فقط (لا دمج في main حسب تعليمات المالك 2026-10-31).

## ما الذي أصلحته الجولة (ثلاث حزم)

### 1) استعادة العمليات اليتيمة بدون Web Locks (G3)
المشكلة: بلا Web Locks، أي مطالبة منتهية الإيجار كانت تُجمّد العملية للأبد (لا استرداد) أو — في النسخة الأقدم — تُسترد فورًا بمجرد انتهاء الإيجار (تنازع مع مرسل حيّ متوقف مؤقتًا).
الحل: `RECOVERY_GRACE_MS = 120s` أعلى من إيجار المطالبة (30s). انتهاء الإيجار وحده **ليس** برهان موت؛ البقاء منتهيًا لأكثر من فترة الغريس هو برهان الموت. الاسترداد عبر `recoverOp` بـ CAS على `(claimedBy, claimExpiresAt)`، يحافظ على `idempotencyKey` الأصلي، والعملية المستردة تُحاول **ضمن الكنسة نفسها**. أسوار UUID على `commitAck`/`patchOpIfOwner` تجعل المرسل القديم المتأخر read-only.

### 2) ترتيب انتقالات الجلسة عبر الألسنة بدون Web Locks (G4)
سلسلة تراجع صريحة: Web Locks ← **ميوتكس localStorage** (رمز + TTL 30s + قراءة راجعة متزامنة؛ آخر كاتب فيزيائي يفوز؛ الإفراج لصاحبه فقط؛ TTL يحرر مالكًا منهارًا) ← تسلسل داخل اللسان. عجز الاكتساب يرمي `session_transition_busy` صراحة.

### 3) إكمال ADR-0010 فعليًا (لا صفحة رسالة)
- **قابلية التثبيت:** `public/manifest.webmanifest` (rtl/ar/standalone، start_url `/today`) + أيقونات براند حقيقية (192/512 أي + maskable) مولّدة برمجيًا + `theme-color`.
- **البيانات المرجعية دون اتصال:** مخزن جديد `refcache` (IDB v2) بمفتاح scope — محمي: يُمسح مع الخروج ويدخل في `isEmpty`/clearScope/clearAll. مواده فقط ما تحتاجه النماذج: مواد (اسم/نوع/وحدة/أسعار مرجعية) وأطراف (اسم/نوع) — **بلا هواتف ولا مجاميع نقدية ولا أرصدة ولا أرباح**.
- **مصدر التحديث:** `GET /api/reference/snapshot` (مصادق، يفشل مغلقًا بدون نطاق ساحة) + تسخين تلقائي بعد كل دخول موثق (`warmReferenceCache`) — فشل الشبكة لا يوقف الواجهة.
- **Service Worker v2:** تعبئة مسبقة لقشرة عدم الاتصال + مخبأ `kayyal-static-*` (cache-first) لـ `_next/static` والأيقونات والمانيفست؛ **أبدًا لا `/api` ولا HTML مصادق ولا RSC**.
- **القشرة الوظيفية** (`offline.html` + `offline.js`): بدون أي اتصال شبكة تعرض الطابور بالمبالغ والحالات والمفاتيح، وتتيح تعديل المسودات **بنفس مفتاح الإرسال الأصلي** (لا عملية جديدة أبدًا)، وتملأ قوائم المواد/الأطراف من آخر لقطة محفوظة بختم «آخر مزامنة»، وزر تحقق يعيد للتطبيق تلقائيًا عند عودة الشبكة.

### 4) إصلاحان وُجدا بالبوابة الصارمة (ليسا ترويض اختبارات)
- **تجميد شاشة الخروج:** بعد نجاح الإنهاء الخادمي لم يكن أحد يرفع قفل الخروج فتبقى الشاشات على «أكّد الخادم إنهاء الجلسة» بلا نهاية. الآن `finishPendingLogout` يبث `unlocked` عند تسوية الدينين، و`useSession` ينقل لشاشة الدخول.
- **مؤشر KPI «حركات اليوم»** أصبح «الحركات المعروضة» — المؤشر يخص آخر ٨ حركات معروضة فقط (توجيه «ما يُعرض يصف المعروض لا اليوم»).
- ملاحظة قشرة العرض: AppShell بعد دمج PR#17 يعرض رقعتين للاتصال (جوال/مكتب) — تعديل الاختبار لاستهداف المرئية فقط.

## حدود صريحة
- منطق الاستعادة بالغريس يعتمد على ساعة الجهاز المحلية (±تزامن)؛ مهلة 120s تحمي من فروق التوقيت العادية، لا من ساعة مضبوطة يدويًا بخبث (سيناريو خارج نطاق التهديد المقبول في ADR-0010).
- القشرة لا ترسل شيئًا من تلقاء نفسها: الإرسال للتطبيق الحقيقي عند العودة — القشرة فقط تحفظ تعديل المسودات بنفس المفاتيح.
- اللقطة المرجعية دون هواتف الأطراف ودون أي مجاميع نقدية — توسيعها يحتاج قرارًا مؤسسيًا جديدًا.
